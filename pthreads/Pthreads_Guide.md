# Pthreads N-Body Simulation Guide

This folder contains the **POSIX Threads (Pthreads)** implementation. Unlike OpenMP's automatic compiler directives, Pthreads requires the developer to manually invoke the operating system to spawn threads, allocate memory workloads, and orchestrate synchronization. 

## 🧠 How It Works

1. **Shared Input**: Reads `../particles.bin` from the root directory to ensure it computes on the exact same universe generated by the Sequential baseline.
2. **Workload Partitioning**: The `main()` function explicitly calculates which chunk of the $N$ particles belongs to which thread (`start` and `end` index logic). This logic is packaged into a `ThreadData` struct.
3. **`pthread_create()`**: Spawns raw OS-level threads. Each thread executes a custom `threadFunc()`.
4. **Independent Execution**: `threadFunc()` unpacks the `ThreadData` struct and calls the `bodyForce()` physics engine, explicitly restricting the calculations to its assigned partition boundaries.
5. **`pthread_join()`**: Synchronizes the simulation by forcing the main process to wait until all threads have completed the current iteration step before updating velocities.
6. **Accuracy Validation**: At the end of the simulation, it loads the `../sequential_output.bin` ground truth and mathematically proves the accuracy by calculating the maximum floating-point deviation.

## 🚀 How to Run

**Prerequisite:** Ensure you have already run the `paramGen` and `sequential_nBody` scripts in the `sequential/` folder to generate the shared `particles.bin` and `sequential_output.bin` files!

### Compile and Run
Compile using `gcc`, linking the math library (`-lm`) and the Pthreads library (`-pthread`):
```bash
gcc -o pthreads_nBody pthreads_nBody.c -lm -pthread
./pthreads_nBody 10000 4
```
