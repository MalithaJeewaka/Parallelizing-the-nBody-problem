# OpenMP N-Body Simulation Guide

This folder contains the **OpenMP** implementation of the N-Body simulation, which uses shared-memory multithreading to accelerate the gravitational calculations.

## 🧠 How It Works

OpenMP allows developers to parallelize C code simply by adding compiler directives (pragmas) over standard `for` loops.

1. **Shared Input**: The program starts by reading `../particles.bin` from the root directory. This ensures it computes on the exact same universe generated by the Sequential baseline.
2. **`#pragma omp parallel for`**: This magic directive tells the compiler to automatically divide the $N$ particles evenly among the available CPU threads.
3. **Data Privacy**: Variables used to accumulate forces (`Fx, Fy, Fz`) are declared inside the loop scope. This means they are private to each thread, inherently preventing race conditions without needing expensive mutex locks.
4. **Accuracy Validation**: At the end of the simulation, the program reads `../sequential_output.bin` (the ground truth generated by the sequential code) and compares it against its own output. It calculates the maximum floating-point deviation to mathematically prove its accuracy.

## 🚀 How to Run

**Prerequisite:** Ensure you have already run the `paramGen` and `sequential_nBody` scripts in the `sequential/` folder to generate the shared `particles.bin` and `sequential_output.bin` files!

### Compile and Run
Compile using `gcc`, linking the math library (`-lm`) and enabling OpenMP (`-fopenmp`):
```bash
gcc -o openMP_version openMP_nBody.c -lm -fopenmp
OMP_NUM_THREADS=4 ./openMP_version 10000 4
```
